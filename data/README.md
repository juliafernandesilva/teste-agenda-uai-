# Arquivos JSON da versão estática

- `catalogo.json`: lojas e categorias iniciais, públicas para qualquer visitante do site.
- Os dados criados pelos formulários não são escritos nesses arquivos. Ficam no `localStorage` de cada navegador.

Para alterar o catálogo inicial compartilhado com todos, edite `catalogo.json` e publique novamente no GitHub Pages. Não inclua contas, senhas ou dados pessoais nesse arquivo.
